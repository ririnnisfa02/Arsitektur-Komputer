1. Arsitektur Komputer Von Neumann

Arsitektur Von Neumann adalah model dasar arsitektur komputer yang dirancang oleh John Von Neumann pada tahun 1945. Model ini menjadi dasar pembahasan komputer modern.

John von Neumann
Tokoh yang namanya digunakan pada model arsitektur ini.

Von Neumann Architecture
Input → CPU ↔ Memory → Output.

Secara sederhana, komputer bekerja dengan menerima input, memproses data menggunakan CPU, menggunakan memori untuk menyimpan data dan instruksi, lalu menghasilkan output.

CPUMenjalankan instruksi dan melakukan operasi aritmatika serta logika.
MemoriTempat menyimpan data dan instruksi program.
InputMemasukkan data ke komputer, misalnya keyboard dan mouse.
OutputMenampilkan hasil pemrosesan, misalnya monitor dan printer.
Contoh: Saat kamu mengetik sebuah kalimat, keyboard memasukkan data, komputer memprosesnya, lalu monitor menampilkan hasilnya.

2. CPU — Pusat Pemrosesan Komputer

CPU atau Central Processing Unit sering disebut “otak” komputer karena bertugas menjalankan instruksi dari program.

Contoh bentuk fisik CPU yang terpasang pada komputer.

Bagian penting CPU

ALUArithmetic Logic Unit melakukan perhitungan dan operasi logika.
Control UnitMengatur alur instruksi yang harus dijalankan.
RegisterTempat penyimpanan data kecil dan cepat di dalam CPU.
Bayangkan: ALU seperti bagian yang menghitung, Control Unit seperti pengatur pekerjaan, dan Register seperti tempat kecil untuk menaruh informasi yang sedang dipakai.

3. Memori: RAM dan ROM

Memori digunakan untuk menyimpan data dan instruksi program. Dalam modul ini, dua jenis yang perlu dipahami adalah RAM dan ROM.

RAM
Menyimpan data sementara saat program berjalan.

ROM
Menyimpan instruksi dasar yang bersifat nonvolatile.

HDD
Contoh penyimpanan sekunder.

SSD
Contoh penyimpanan sekunder berbasis flash.

RAM — sementaraDigunakan ketika program sedang berjalan. Data di RAM hilang ketika komputer dimatikan.
ROM — permanenMenyimpan instruksi dasar yang diperlukan saat komputer dinyalakan.
Ingat: RAM bukan tempat menyimpan file secara permanen. Ketika komputer mati, data sementara di RAM hilang.
Catatan penting: HDD dan SSD termasuk penyimpanan sekunder nonvolatile. Keduanya tidak sama dengan ROM, tetapi sama-sama dapat mempertahankan data tanpa listrik.

4. Perangkat Input dan Output

Input adalah cara komputer menerima data. Output adalah cara komputer menyampaikan hasil kepada pengguna.

Perangkat Input

Contohnya keyboard, mouse, scanner, dan microphone. Perangkat tersebut digunakan untuk memasukkan data atau perintah.

Perangkat Output

Contohnya monitor, printer, dan speaker. Perangkat tersebut digunakan untuk menampilkan hasil pemrosesan.

Input→Proses→Output

5. Siklus Instruksi: Fetch → Decode → Execute

Siklus instruksi adalah proses yang dilakukan CPU untuk menjalankan satu instruksi program. Siklus ini terjadi berulang kali saat komputer menjalankan program.

1. FetchCPU mengambil instruksi dari memori dan menyimpannya di register.
2. DecodeCPU menerjemahkan instruksi agar dapat dipahami oleh bagian yang akan menjalankannya.
3. ExecuteCPU menjalankan instruksi, misalnya menghitung, membandingkan, atau memindahkan data.
Store — opsionalJika diperlukan, hasil eksekusi disimpan kembali ke memori.
Contoh: Jika instruksinya “Tambah 5 + 3”, CPU mengambil instruksi, menerjemahkannya sebagai operasi penjumlahan, kemudian menjalankan perhitungan tersebut.

Fetch → Decode → Execute.

6. Sistem Operasi

Sistem operasi atau Operating System (OS) adalah perangkat lunak sistem yang mengelola sumber daya perangkat keras dan perangkat lunak serta menyediakan layanan bagi program aplikasi.

Contoh Sistem Operasi

Windows
Sistem operasi dari Microsoft.
macOS
Sistem operasi untuk komputer Mac.
Linux
Keluarga sistem operasi berbasis kernel Linux.

Sistem operasi menjadi penghubung antara pengguna, aplikasi, dan perangkat keras. Contohnya adalah Windows, macOS, Linux, Android, dan iOS.

Contoh sehari-hari: Saat kamu membuka kamera di smartphone, sistem operasi membantu aplikasi menggunakan kamera, memori, prosesor, dan layar.

7. Fungsi Utama Sistem Operasi

Dalam modul, tiga fungsi utama yang menjadi fokus pembelajaran adalah manajemen memori, manajemen file, dan manajemen proses.

1. Manajemen Memori

Mengatur alokasi RAM untuk program yang sedang berjalan.

2. Manajemen File

Mengatur penyimpanan, pengorganisasian, dan penamaan file.

3. Manajemen Proses

Mengatur penjadwalan dan eksekusi program yang sedang berjalan.

4. Manajemen Input/Output

Mengatur komunikasi perangkat input/output dengan sistem.

5. Pengguna & Keamanan

Mengelola akun, hak akses, dan membantu melindungi sistem.
Coba pikirkan: Kamu membuka game dan browser secara bersamaan. Fungsi OS apa yang berkaitan dengan pengaturan program yang sedang berjalan?
Manajemen proses.

8. Hubungan Semua Komponen

Sekarang kita gabungkan semua konsep. Ketika kamu menggunakan komputer, banyak bagian bekerja bersama.

Misalnya saat mengetik di keyboard:

  1. Input: keyboard menerima ketikanmu.
  2. Proses: CPU menjalankan instruksi melalui siklus fetch, decode, dan execute.
  3. Memori: data dan instruksi yang diperlukan disimpan sementara di RAM.
  4. Output: monitor menampilkan hasil.
  5. Sistem Operasi: membantu mengatur proses, memori, file, serta perangkat input/output.
Inti pemahaman: Komputer bukan sekadar CPU. Komputer bekerja sebagai sebuah sistem yang terdiri dari berbagai komponen yang saling berhubungan.
